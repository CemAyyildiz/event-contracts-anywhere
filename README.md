# Event Contracts Anywhere

DreamDEX Event Contracts **where people already are** — Telegram Mini App first. Session wallet on device, you deposit, real Shannon fills.

**Hackathon:** Somnia × DreamDEX Event Contracts · DoraHacks  
**Deadline:** 2026-09-11 21:00

## Product

1. Open Mini App (`/tma`) → session EOA created  
2. Deposit STT + tUSDC  
3. Up/Down on live DreamDEX Event Contracts  
4. PnL on **your** address · keys never leave the client  

Docs: [product lock](docs/product-lock.md) · [architecture](docs/architecture.md) · [spike](docs/spike.md) · [SDK feedback](docs/sdk-feedback.md)
